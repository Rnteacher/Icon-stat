# Icon Stat

Icon Stat adds a native-style statistic to Geometry Dash player profiles showing the total number of icons that player has unlocked.

Click the statistic to see a breakdown for Cube, Ship, Ball, UFO, Wave, Robot, Spider, Swing, and Jetpack. Each category opens a gallery of the player's actual unlocked icons, and **View All** shows their complete collection.

Publishing is off by default. Writes and deletion are authenticated through Argon; Icon Stat never asks for or sends your Geometry Dash password to the Icon Stat server.

The server URL is configurable in settings. Better Unlock Info and Colorful Icons are supported through their normal public hooks.
